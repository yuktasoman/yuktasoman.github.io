# Yukta Soman | Project Management Portfolio

Live site: https://mayur-dokras.github.io/upgraded-y-portfolio/

A static, single-file portfolio site (no build step). Open `index.html` locally, or serve it with GitHub Pages from the `main` branch root.

- `index.html`: page content, styles and scripts (3D starfield, scroll effects, experience Gantt, skills matrix, Ask the portfolio, full-screen image viewer)
- `assets/img/`: images
- PDFs: CV and evidence portfolio downloads

To update content, edit the data arrays near the top of the `<script>` block in `index.html`: `roles` (experience timeline), `cases` (case studies), `gallery` (Moments), `matrix` (skills) and `kb` (Ask the portfolio answers).
